The Mouse UDLR settings button and dialog screenshots use 0.20.16 with synthetic profile data and default 64 pt / 30 ms hold / 20 ms wait values and separate Trackball/Paddle tabs, each with four drop-downs initially set to ↑/↓/←/→ and Reset to defaults in the center. Reset affects only the displayed tab; the three numeric settings are shared. The Paddle tab additionally offers Virtual Rolling with sensitivity, a nine-choice rotation-step list (default 30°), output-stick and reversal controls; its 0.20.16 screenshot shows the initial values. The Trackball tab names its original click mode Virtual Rolling and also offers Hold. The Hold screenshot shows the first opening of saved Hold with its dedicated 1 pt threshold and default ↑/↓/←/→ assignments. The common click threshold/timing fields remain visible but disabled. Every mode retains all its parameter groups in place and greys out unused controls; tab/mode changes do not move the tab region. The Paddle Virtual Rolling capture retains customized B/A left/right assignments in its disabled direction lists; its rolling options show their initial values. Hold's threshold has no range annotation. The LED RGB image also uses 0.20.10 and shows the square eyedropper icon. The Mouse UDLR dialog omits the extra hold/wait explanation below its fields. The movement-conversion screenshot uses 0.20.7 with both conversion options enabled and pointer gain still editable. The cursor gains are separate hidden settings. Normal combined output keeps pointer movement active while adding clicks, trackball-held controls or the paddle Virtual Rolling stick direction. The older movement-conversion capture uses the previous paddle checkbox label; the current label is Enable conversion. The UDLR preview shows the read-only common threshold without displaying cursor gains. The paddle-axis screenshot uses the 0.20.2 GUI. Rapid-fire and button-shift screenshots use 0.20.1 with the shared save reminder. Main-window and firmware-update references retain 0.19.0 images; the axis reference is from 0.16.0. Their labels describe those captures. Current profile editing uses **Save profile to device**.
