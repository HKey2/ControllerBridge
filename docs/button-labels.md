# Button labels and assignment indicators

Choose a system from the list between the upper function buttons and Capture/Home in the gamepad layout. The list fits its longest system name and is centered between the left and right button groups. The selected system name remains visible there. Choose **Save settings to device** to store it with the profile. Reconnection, profile duplication, reordering, JSON export/import, and all-slot backup/restore preserve this choice. Existing profiles start with Switch labels after updating to firmware 0.33.0. Older configurators cannot read the new profile format; retain an older backup if you intend to return to older firmware.

The choices are Switch, Xbox 360, DS3, PS4, and POLYMEGA layouts for PlayStation, Saturn, Saturn fighting games, Mega Drive, Mega Drive fighting games, Super Nintendo, Neo Geo CD, NES, and PC Engine. DS3 uses SELECT, START and PS, with L3/R3 for the stick clicks. Install the bundled firmware to save this choice, even if the device already reports 0.33.0. Selecting a label set does not add a console output mode.

Only the names change. Positions, existing assignments, rapid fire, toggle, shift, direction conversion, and actual USB output retain their existing meaning. The host/output mode does not select labels automatically. Related settings use the same selected names. Where a name is unavailable, instructions and lists identify the output as **Unnamed** followed by its position number; the button face remains blank.

Unnamed buttons can still be selected, assigned, cleared, and saved. A missing name is distinct from a missing assignment. This converter does not suppress an output because the selected system lacks a name for it. The receiving system determines which transmitted inputs it uses; an output format without a corresponding signal, such as Capture in XInput, does not gain that signal by assigning it.

The selected button has a blue face. Assigned buttons have a darker blue face and a thick blue outline, including unnamed buttons. The Button shift button has a solid purple vertical bar inset from its left edge, matching the shift outline. A purple outer outline indicates an explicitly assigned shifted mapping; both outlines appear when both mappings exist. Inherited mappings and shifted **No output** do not add a purple outline. Select a button to inspect its mapping or assign a physical input, then choose **Clear mapping** to remove that assignment. Save to the device to apply changes. The shifted page also uses the purple outline for an explicit shifted assignment; an inherited assignment is distinguished in the tooltip. **No output** suppresses the inherited output; **Inherit from main** restores inheritance. The main page's blue outline describes the main mapping; its purple outline also reveals a shifted-only mapping. Clearing a selected mapping removes its assignment outline while retaining the blue selection face.

POLYMEGA names are reference layouts, not automatic game detection. Games and controller configurations can use different mappings. Saturn/Mega Drive fighting layouts are provisional candidates. PC Engine IV/VI positions are unresolved and remain unnamed. Verify the labels in the game's own control settings; changing a label selection does not remap the controls for the game.
